Tecnologías

Herramientas con las que se programará y probará la plataforma: HTML y CSS para las páginas, PHP para la lógica y MySQL para los datos.

Parte del proyecto Tecnología ¿Para qué la usamos?
Interfaz (frontend)HTML5 y CSS3Estructura y estilos de las páginas que ve el usuario
Diseño responsivoCSS con media queriesAdaptar la página a teléfono, tableta y computadora sin usar frameworks
Programación del servidor (backend)PHP 8Registro e inicio de sesión, referidos, puntos, canjes y las validaciones de cada proceso
Base de datosMySQL (con phpMyAdmin)Guardar socios, referidos, puntos, recompensas y contenidos
Servidor localMAMP (Apache, PHP y MySQL)Probar la plataforma en nuestras computadoras
SeguridadSesiones de PHP, password_hash() y PDOControlar el acceso por rol, cifrar contraseñas y evitar inyección SQL; HTTPS al publicar
Control de versionesGit y GitHubTrabajar en equipo y guardar el historial
EditorVisual Studio CodeEscribir el código
Diseño de prototiposGoogle Stitch y FigmaDiseñar y mostrar las pantallas antes de programarlas

¿Por qué estas?

  • PHP y MySQL ya vienen incluidos en MAMP: no hay que instalar nada más ni aprender un framework.
  • PHP se escribe junto con el HTML, así que las páginas que ya tenemos solo pasan de .html a .php.
  • phpMyAdmin, incluido en MAMP, permite crear y revisar las tablas de la base de datos de forma visual.
  • Todas son gratuitas, tienen mucha documentación en español y el hosting con PHP y MySQL es económico.
