Requisitos no funcionales

Condiciones de calidad que deberá cumplir la aplicación.

Código Categoría Descripción
RNF01SeguridadLas contraseñas deben almacenarse cifradas y toda la comunicación debe realizarse mediante HTTPS.
RNF02SeguridadCada usuario solo debe acceder a las funciones de su rol (Socio, Administrador o Gestor de contenidos).
RNF03SeguridadLos datos de socios y referidos deben tratarse conforme a la Ley Orgánica de Protección de Datos Personales del Ecuador.
RNF04UsabilidadLas acciones principales (registrar un referido, inscribirse en una actividad, consultar puntos) deben realizarse en máximo 3 clics desde el inicio.
RNF05AccesibilidadLa aplicación debe cumplir las pautas WCAG 2.1 nivel AA (contraste suficiente, texto alternativo en imágenes y navegación por teclado).
RNF06RendimientoLas páginas principales deben cargar en menos de 3 segundos.
RNF07CompatibilidadLa aplicación debe funcionar en las versiones actuales de Chrome, Firefox, Edge y Safari, y adaptarse a teléfonos, tabletas y computadoras.
RNF08DisponibilidadLa aplicación debe estar disponible al menos el 99 % del tiempo, con copias de seguridad diarias de la base de datos.
